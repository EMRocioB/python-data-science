# Python - Data Science & Machine Learning

Proyectos desarrollados en Python para la carrera de Licenciatura en Sistemas de Información (UNNE), abarcando Machine Learning, análisis de datos y procesamiento de archivos.

## Proyectos

### Clasificador de Imágenes - Perros y Gatos
Trabajo Integrador de la asignatura **Inteligencia Artificial** (2023).
- Clasificación de imágenes usando **TensorFlow** y **TensorFlow Datasets**
- Preprocesamiento de imágenes con **OpenCV** (escala de grises, redimensionado)
- Visualización de datasets con **Matplotlib**
- Dataset: `cats_vs_dogs` de TensorFlow Datasets

### Análisis de Datos con Pandas
- Importación de datos desde **Google Sheets**
- Análisis exploratorio con **Pandas** y **NumPy**
- Visualizaciones con **Matplotlib** y **Seaborn**

### Procesamiento de PDFs
- Extracción y manipulación de archivos PDF con **PyPDF2**

## Tecnologías

| Librería | Uso |
|----------|-----|
| TensorFlow | Machine Learning |
| OpenCV | Procesamiento de imágenes |
| Pandas / NumPy | Análisis de datos |
| Matplotlib / Seaborn | Visualización |
| PyPDF2 | Procesamiento de PDFs |
